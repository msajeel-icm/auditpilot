# AuditPilot

Next.js 14 App Router scaffold for Medicaid audit prep (IDD/LTC).

## Stack

- Next.js 14 + TypeScript (strict) + Tailwind + shadcn/ui
- pnpm · Vercel AI SDK · Zod · Zustand · Framer Motion · Lucide

## Scripts

```bash
pnpm install
pnpm dev
pnpm exec tsc --noEmit
pnpm lint
```

Theme tokens and AppShell land in a follow-up task. DeepSeek wiring is phase 3.
